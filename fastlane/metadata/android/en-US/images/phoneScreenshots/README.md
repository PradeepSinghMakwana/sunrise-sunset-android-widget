# Store screenshots

The release workflow runs an Android emulator UI test and captures a genuine screenshot of the running app setup screen using UI Automator. It saves the PNG here and attaches it to the GitHub Release.

Automated capture:
- `01-app-setup.png`: the actual app setup screen rendered by Android on an emulator.

This is a real emulator screenshot, not a mockup or generated image. Review it before store submission. A separate screenshot showing the widget placed on a launcher home screen is not yet automated and must not be represented by the app-screen capture.
