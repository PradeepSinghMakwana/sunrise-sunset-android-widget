# Store screenshots

Add genuine screenshots of the running app here before submitting the listing to F-Droid or another app store.

Recommended:
- At least one screenshot showing the widget on a real Android home screen.
- A screenshot of the app's location setup screen.
- Use unedited screenshots from the app; do not use mockups or fabricated UI.

The release workflow checks for screenshot files and records whether they are present. It will not invent screenshots.
